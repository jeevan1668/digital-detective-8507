# Mission 1 Task - Know Your Computer

## Task 1.1 - IPOS example: typing and saving a document

| Stage | What happens | Component |
| :--- | :--- | :--- |
| Input | Text is typed and editing commands are given. | Keyboard and trackpad |
| Processing | The computer works with the text and keeps active work in memory. | CPU and RAM |
| Output | The document appears on screen. | Display |
| Storage | Saving keeps the document for later. | SSD |

## Task 1.2 - Hardware and software

### Hardware

| Item | Purpose |
| :--- | :--- |
| Keyboard | Enters text |
| Trackpad | Controls the pointer |
| Display | Shows information |
| SSD | Stores files |

### Software

| Software | Type | Purpose |
| :--- | :--- | :--- |
| macOS | Operating system | Manages the computer and its resources |
| Visual Studio Code | Application | Edits code and text |
| Google Chrome | Application | Browses the web |
| Disk Utility | Utility | Checks and manages storage devices |
