# Mission 1 - Know Your Computer

## Task 1.1 - Trace One Activity Using IPOS

### Activity: Typing and Saving a Document on a MacBook

| Stage | What Happens? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard and give commands using the trackpad. | Keyboard, Trackpad |
| Processing | The processor handles the typed information, while RAM temporarily holds the working data. | CPU, RAM |
| Output | The document appears on the display so I can read and edit it. | Screen / Display |
| Storage | When I save the document, it is stored for future access. | SSD |

### Explanation

First, I enter text using the keyboard. The CPU processes
the input and RAM temporarily holds the information.
The result appears on the screen. When I save the
document, it is stored on the SSD and can be opened later.

This demonstrates how input, processing, output and
storage work together in a computer system.

## Task 1.2 - Identify Hardware and Software

### Hardware

| Item | Classification | Software Type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text |
| Trackpad | Hardware | Not applicable | Used to control the pointer |
| Display | Hardware | Not applicable | Shows information and output |
| SSD | Hardware | Not applicable | Stores files and data |

### Software

| Item | Classification | Software Type | Purpose |
|---|---|---|---|
| macOS | Software | Operating System | Manages computer resources and hardware |
| Visual Studio Code | Software | Application Software | Used to write and edit code |
| Google Chrome | Software | Application Software | Used to browse the internet |
| Disk Utility | Software | Utility Software | Used to manage and check storage disks |

### Understanding

Hardware refers to the physical components of a
computer that we can touch and use.

Software refers to the programs and instructions that
tell the hardware what to do.

Operating system software manages the computer,
application software helps users perform specific
tasks, and utility software helps maintain the system.

## Task 1.3 - Computer Systems Around Me

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| ATM | Withdraw cash and check account information | PIN entered by user | Cash dispensed |
| Traffic Signal | Control traffic movement | Sensor input | Red, yellow or green light |
| Railway Ticket Machine | Generate railway tickets | Journey details | Printed ticket |

### Understanding

Computer-based systems are present in many everyday
activities. They accept input, process information and
produce useful output.

An ATM processes banking requests, a traffic signal
controls vehicle movement, and a railway ticket machine
processes journey details to generate tickets.
