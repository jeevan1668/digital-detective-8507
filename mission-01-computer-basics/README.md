# Mission 1 - Know Your Computer

## 1. Task / objective
Explain how a computer uses input, processing, output and storage; identify hardware and software; give everyday computer-system examples.

## 2. Work completed
### Task 1.1 - Trace one activity using IPOS
Activity: typing and saving a document on a MacBook.

| Stage | What happens | Hardware / component |
| :--- | :--- | :--- |
| Input | Text is typed and editing commands are given. | Keyboard and trackpad |
| Processing | The computer works with the text while RAM holds active data. | CPU and RAM |
| Output | The document appears on screen. | Display |
| Storage | Saving keeps the document for later. | SSD |

### Task 1.2 - Identify hardware and software

| Item | Classification | Software type | Purpose |
| :--- | :--- | :--- | :--- |
| Keyboard | Hardware | Not applicable | Enters text |
| Trackpad | Hardware | Not applicable | Controls the pointer |
| Display | Hardware | Not applicable | Shows information |
| SSD | Hardware | Not applicable | Stores files |
| macOS | Software | Operating system | Manages computer resources |
| Visual Studio Code | Software | Application | Edits code and text |
| Google Chrome | Software | Application | Browses the web |

## 4. My understanding
IPOS describes how a computer handles information: it receives input, processes it, produces output and can store the result. Hardware is the physical equipment. Software is the set of programs that tell the equipment what to do. Operating systems manage resources, applications help users complete tasks and utilities maintain the computer.

## 5. Difficulties faced
The difference between processing and storage was confusing at first.

## 6. How I resolved them
The document example helped separate them: CPU and RAM work with the text while it is being edited; the SSD keeps the saved file for later.
